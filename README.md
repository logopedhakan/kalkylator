# Kalkylator

En tydlig kalkylator i webbläsaren med stora knappar. Räknesätten kan visas och
döljas ett och ett (addition, subtraktion, multiplikation, division, parenteser,
roten ur, upphöjt till), så att den kan anpassas efter den som räknar.

**Använd den här:** <https://logopedhakan.github.io/kalkylator/>

- Historik över uträkningar, ångra, kopiera och klistra in
- Ljust och mörkt läge (följer datorn, eller välj själv)
- Tangentbord: siffror, `+ - * / ^ ( )`, `Enter` = likamed, `Backspace` = sudda, `Esc` = rensa
- Allt ligger i en enda fil, [index.html](index.html). Den hämtar inget från internet,
  och inställningar och historik sparas bara i den egna webbläsaren.

## Publicera en ändring

Ändra `index.html`, gör en commit och tryck **Push origin** i GitHub Desktop.
GitHub Pages visar den nya versionen efter en minut eller två.
